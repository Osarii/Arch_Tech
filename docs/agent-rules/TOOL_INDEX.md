# Tool Index

| Tool | Purpose | When to Use | When Not to Use |
|---|---|---|---|
| **Serena** | Semantic code search & symbol lookup | Multi-file refactors, symbol definitions, large unfamiliar files | Small known files or simple single-line changes |
| **RTK** | Terminal output filtering and condensation | Large log commands (build, lint, test, git diff) | When exact line-by-line output is needed |
| **Ponytail** | Enforce YAGNI & prevent over-engineering | Before adding new abstraction layers or services | Core concrete requirements |
| **Vitest** | Fast domain & unit testing | Testing stores, parsers, tree builders, metadata | Full visual/browser validation |
| **Playwright** | Real browser E2E validation | Canvas mounting, UI interaction, end-to-end workflows | Fast pure logic testing |
